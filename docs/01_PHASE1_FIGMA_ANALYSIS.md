## 4. ملاحظات على التصميم عولجت أثناء التنفيذ

1. تذبذب كتابة الأرقام بين «214» و«٢١٤» بين الشاشات ← توحيد الأرقام اللاتينية (المعتمدة في الإعداد المحلي الليبي ar_LY).
2. «214 كم» مقابل «198كم» دون مسافة ← تنسيق موحّد عبر مرشّح `km`.
3. «87٪» بعلامة نسبة عربية مع أرقام لاتينية ← توحيد «87%».
4. أسماء طبقات عامة (Container/Background) ← لا أثر على التنفيذ، يُنصح بتسميتها في Figma لتسهيل التسليم.
5. مؤشر «معدل الوضوح» غير معرّف المصدر في التصميم ← صُمّم كقيمة تشغيلية يحدّثها المشرف لكل قاطع (مع الطقس)، ويظهر «—» عند عدم توفرها بدلاً من رقم مختلق.

## 5. الشاشات والميزات الناقصة في Figma (صُمّمت بنفس الهوية)

تسجيل الدخول / إنشاء حساب / استعادة كلمة المرور، صفحة تأكيد إرسال البلاغ (الرقم المرجعي)، تفاصيل البلاغ ومراحله، متابعة بلاغ زائر، خريطة الطريق، صفحة تنبيهات الطريق العامة، صفحة التثبيت (PWA)، صفحة عدم الاتصال، صفحات الأخطاء، **لوحة التحكم الإدارية كاملة** (المؤشرات، إدارة البلاغات، الإسناد، المستخدمون، الموظفون، الفرق، التصنيفات، القواطع والنقاط المرجعية، الإعلانات، رسائل الدعم، التحليلات، الإعدادات، سجل التدقيق)، وتخطيطات سطح المكتب.
