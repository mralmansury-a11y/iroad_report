## الطلب 2 — الموقع في إنشاء البلاغ: «استخدم موقعي» و«اختر من الخريطة» فقط

| الملف | التعديل |
|---|---|
| `app/templates/reports/new.html` | استُبدل قسم **الموقع** (`<fieldset>` الثاني) بالكامل: **أُزيل حقلا الكيلومتر والقاطع**، وبقي زرّان كبيران «استخدم موقعي» و«اختر من الخريطة»، مع بطاقة حالة (لم يُحدَّد / تم / تحذير / خطأ) تعرض الكيلومتر والقاطع المحسوبين والإحداثيات والدقة. الحقول المخفية: `latitude`، `longitude`، `location_source` |
| `app/static/js/report-form.js` | استُبدل منطق الموقع: GPS مع رسائل أخطاء دقيقة، وخريطة اختيار بعلامة قابلة للسحب (أو بالنقر)، وتحديث فوري للكيلومتر والقاطع، ومنع الإرسال دون موقع. المسودة تحفظ الإحداثيات بدل الكيلومتر |
| `app/static/js/app.js` | دالة مشتركة جديدة `IR.geolocate()` (بعد `IR.api`) + ظل الترويسة عند التمرير |
| `app/static/js/home.js` | زر «استخدم موقعي» في الرئيسية يستخدم نفس الدالة ونفس الرسائل |
| `app/reports/forms.py` | حُذف `km_marker` و`road_section_id` من `ReportForm`؛ التحقق يشترط الإحداثيات |
| `app/reports/routes.py` | **الخادم يحسب الكيلومتر والقاطع من الإحداثيات** (`km_from_coordinates` + `section_for_km`) ولا يثق بأي كيلومتر يرسله المتصفح؛ حُذفت الدالة `_sections()` |
| `app/__init__.py` | سياسة CSP تسمح تلقائياً بخادم البلاطات المضبوط في `MAP_TILE_URL` |
| `app/static/css/app.css` | أنماط `ir-loc-picker` و`ir-loc-btn` و`ir-pick-map`، وإصلاح Leaflet في الاتجاه RTL (`.leaflet-container { direction: ltr }`) |
| `app/utils/i18n.py` | نصوص JavaScript جديدة لرسائل الموقع |

### سبب تعطّل زر «استخدم موقعي» وكيف عولج
1. **السبب الرئيسي:** المتصفحات **لا تسمح بتحديد الموقع إلا عبر HTTPS** (أو `localhost`). عند فتح الموقع عبر `http://` أو عنوان IP كان المتصفح يرفض فوراً، والرسالة السابقة كانت مبهمة. الآن تظهر رسالة صريحة: «لا يسمح المتصفح بتحديد الموقع إلا عبر اتصال آمن (HTTPS)». **الحل الدائم:** تشغيل الموقع عبر HTTPS (القسم 7 من دليل النشر).
2. كانت المهلة 15 ثانية بدقة عالية فقط، فيفشل الطلب على الحواسيب التي لا تحتوي GPS. الآن تُجرَّب الدقة العالية لمدة 12 ثانية، ثم موقع الشبكة لمدة 20 ثانية.
3. عندما تقع النقطة خارج النقاط المرجعية للطريق كانت تظهر رسالة توحي بالفشل. الآن **تُحفَظ الإحداثيات ويُقبل البلاغ**، ويحدد فريق الطريق الكيلومتر لاحقاً.
4. لكل حالة رسالة مخصصة: الإذن مرفوض (مع إرشاد لأيقونة القفل)، انتهاء المهلة، المتصفح غير داعم.
5. خريطة Leaflet كانت تتأثر باتجاه RTL، فأصبح اتجاهها ثابتاً LTR داخل الصفحة العربية.
