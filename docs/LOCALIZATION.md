# اللغات والاتجاه (Arabic / English, RTL / LTR)

## اختيار اللغة (بالترتيب)
1. معامل `?lang=ar|en` (يستخدمه رابط بدء الـ PWA).
2. تفضيل الحساب `users.locale` (يُحفظ عند التبديل وهو مسجّل الدخول).
3. كوكي `lang` / الجلسة للزائر (سنة كاملة).
4. **العربية افتراضياً** لكل زائر جديد.

التبديل عبر `/lang/<code>` يعيد المستخدم إلى **نفس الصفحة** (مع إزالة `?lang` القديم).

## الاتجاه
* `<html lang dir>` يتغيّر ديناميكياً؛ يُحمَّل `bootstrap.rtl.min.css` للعربية و`bootstrap.min.css` للإنجليزية.
* CSS المشروع يستخدم الخصائص المنطقية فقط (`margin-inline-*`، `padding-inline-*`، `inset-inline-*`، `border-inline-start`، `text-align: start`).
* الأيقونات الاتجاهية تُعكس بالفئة `.ir-flip`؛ الرسوم البيانية تستخدم `rtl`/`reverse`؛ رسم الطريق في الرئيسية يعكس اتجاه تزايد الكيلومترات.
* الأرقام المرجعية والهواتف والإحداثيات داخل `<bdi dir="ltr">` لمنع اختلاط الاتجاهات.

## الترجمة
* مصدر النصوص: الإنجليزية (msgid) في القوالب والكود عبر `_()` و`_l()`، وللـ JavaScript عبر قاموس يُترجم في الخادم (`js_strings()`).
* الملفات: `translations/ar/LC_MESSAGES/messages.po` و`translations/en/...`.
* إعادة البناء والتحقق من الاكتمال:
  ```bash
  python scripts/build_translations.py          # يستخرج، يحدّث، يملأ، يترجم .mo — يفشل عند نقص أي ترجمة عربية
  python scripts/build_translations.py --check
  ```
* لإضافة نص جديد: اكتبه بـ `_("...")`، شغّل السكربت، أضف ترجمته في `messages.po` (أو `scripts/i18n_ar.py`)، أعد التشغيل.

## المحتوى من قاعدة البيانات
التصنيفات، القواطع، الحالات، الفرق، الإعلانات: حقلا الاسم العربي والإنجليزي إلزاميان في لوحة التحكم. نص المستخدم يبقى بلغته الأصلية ويُعرض مع `dir="auto"` و`lang` المناسب.
