# تطبيق الويب التقدّمي (PWA)

## المكوّنات
| المكوّن | الموقع |
|---|---|
| Manifest ديناميكي ثنائي اللغة | `/manifest.webmanifest?lang=ar|en` (اسم، اسم قصير، وصف، `dir`، `standalone`، ألوان، اتجاه، 10 أيقونات منها maskable، 3 اختصارات) |
| Service Worker | `/sw.js` (من `app/static/js/sw.js`) نطاقه `/` |
| الأيقونات | `app/static/icons/` — تُعاد توليدها من الشعار الرسمي: `python scripts/build_icons.py logo.png` |

## استراتيجيات التخزين
| النوع | الاستراتيجية |
|---|---|
| الملفات الثابتة وغلاف التطبيق | Cache-first؛ اسم الذاكرة يحمل بصمة تلقائية لمحتوى `/static` (تتغيّر مع كل نشر) |
| الصفحات العامة (الرئيسية، البلاغات، نموذج الإبلاغ، الخريطة…) | Network-first ← النسخة المحفوظة ← `/offline` |
| بيانات عامة (`/api/v1/road|meta|home|reports/map`) | Network-first ← النسخة المحفوظة |
| `/admin` `/auth` `/notifications` `/profile` المرفقات `/api/v1/me|notifications|push|auth` | **شبكة فقط — لا تخزين إطلاقاً** |
| أي استجابة `no-store/private` (كل صفحات المستخدم المسجّل) | لا تُخزَّن |
| طلبات غير GET | لا يعترضها الـ SW |

* **التحديث المضبوط:** النسخة الجديدة تنتظر؛ يظهر للمستخدم «يتوفر إصدار جديد — تحديث» ثم `SKIP_WAITING`. لا إعادة تحميل في أول تثبيت.
* **التنظيف:** حذف الذاكرات القديمة عند `activate`؛ حذف ذاكرة الصفحات عند تسجيل الخروج.

## العمل دون اتصال
* شريط «أنت غير متصل» يظهر/يختفي تلقائياً.
* نموذج البلاغ يحفظ **مسودة نصية** محلياً (localStorage) أثناء الكتابة وعند الإرسال دون اتصال، ويعرض: «لم يُرسَل البلاغ، وقد حُفظ كمسودة». تُستعاد المسودة تلقائياً ولا تُحذف إلا بعد تأكيد الخادم (HTTP 201).
* الصور لا تُحفظ في المسودة (حجماً وخصوصية) ويُطلب إرفاقها عند الإرسال.
* قبل الإرسال يُجلب رمز CSRF جديد (لصفحات مستعادة من الذاكرة).

## الإشعارات الفورية (Web Push)
1. `flask vapid-keys` ثم وضع المفتاحين في ملف البيئة (الخاص لا يغادر الخادم).
2. يطلب المستخدم التفعيل بنفسه (زر صريح) ← `PushManager.subscribe` ← `/api/v1/push/subscribe`.
3. الإرسال: عند تغيّر حالة البلاغ، الإسناد، النقاط، الإعلانات/الطوارئ؛ النص بلغة المشترك واتجاهها.
4. التنظيف: حذف الاشتراك تلقائياً عند 404/410، أو بعد 5 إخفاقات (`flask cleanup-push`)، وإعادة المزامنة تلقائياً عند تغيّر الاشتراك.

## دعم المنصّات
| المنصة | التثبيت | Push |
|---|---|---|
| Android Chrome/Edge/Samsung | زر «تثبيت» داخل التطبيق | ✔ |
| Windows/macOS/Linux Chrome/Edge | أيقونة التثبيت | ✔ |
| iOS/iPadOS Safari ≥ 16.4 | «مشاركة ← إضافة إلى الشاشة الرئيسية» (صفحة إرشادية) | ✔ بعد التثبيت فقط |
| Firefox سطح المكتب | لا تثبيت | ✔ |

> يتطلب الـ PWA والـ Push بروتوكول HTTPS (أو localhost للتطوير).
