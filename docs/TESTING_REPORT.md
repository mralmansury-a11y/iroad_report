## 3. فحوصات إضافية
* `flask db check` ← لا فروق بين النماذج والترحيل.
* توليد DDL لمحرك MariaDB من الترحيل (`flask db upgrade --sql`) ← `deploy/sql/schema_mariadb.sql` (31 جدولاً).
* تشغيل Gunicorn بملف الإعداد الفعلي + `/healthz` ← `{"ok": true}`.
* حارس الإنتاج يرفض SQLite ويرفض التشغيل دون أسرار.
* `pyflakes` نظيف؛ `bash -n` لكل سكربتات النشر.
* مفاتيح VAPID المولّدة متوافقة مع py-vapid (توقيع ناجح).

## 4. ما لم يُختبر في هذه البيئة (يُستكمل عند النشر)
| البند | السبب | الإجراء المطلوب |
|---|---|---|
| التشغيل على **MariaDB حقيقية** | لا يتوفر خادم MariaDB في بيئة البناء؛ الاختبارات الآلية تعمل على SQLite في الذاكرة | `TEST_DATABASE_URL=mysql+pymysql://… pytest` على خادم الاختبار، و`flask db upgrade` على قاعدة فارغة |
| بلاطات الخرائط OSM | الوصول الشبكي الخارجي محجوب في بيئة البناء | التحقق بصرياً بعد النشر |
| تسليم Web Push فعلي إلى FCM/Mozilla/Apple | لا وصول لخدمات Push | اختبار على Android Chrome و iOS 16.4+ بعد HTTPS |
| التثبيت الفعلي على Android/iOS | يتطلب أجهزة و HTTPS | قائمة التحقق في `DEPLOYMENT.md` §8 |
| Nginx + Let's Encrypt + systemd على الخادم | يتطلب الخادم الفعلي | `preflight_inspect.sh` ثم خطوات النشر |
| HEIC (صور iPhone) | يتطلب `pillow-heif` و libheif | تثبيت اختياري (معلّق في requirements) |
